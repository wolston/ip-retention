Inspiring Prayer Retention Intelligence

Privacy Policy

Effective date: 20 October 2026

Purpose and access

This is a personal desktop tool used only by the owner of the Inspiring Prayer YouTube channel to read the channel’s own YouTube Analytics and produce retention reports. The app requests only the youtube.readonly and yt-analytics.readonly scopes. Access is read-only.

Data handling and security

Data is stored locally on the owner’s PC and is never sold or shared. Authentication tokens are kept in Windows Credential Manager.

Revoke access

You can revoke the app’s access at Google Account permissions.

Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Contact
